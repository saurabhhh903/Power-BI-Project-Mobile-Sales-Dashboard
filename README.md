# 📱 Mobile Sales Dashboard | Power BI

An interactive **Power BI Dashboard** built to analyze mobile sales performance through dynamic visualizations, KPI tracking, and business insights. This dashboard helps monitor sales trends, compare performance over time, and support data-driven decision making.

## 🚀 Key Features

- 📊 Executive KPI Cards (Sales, Quantity, Transactions & Average Price)
- 📅 Month-to-Date (MTD) Sales Analysis
- 📈 Same Period Last Year (SPLY) Comparison
- 🌍 Sales by City (Map Visual)
- 📆 Monthly & Daily Sales Trend Analysis
- 🏆 Top 5 Brand Performance
- 📱 Mobile Model-wise Sales Analysis
- 💳 Payment Method Distribution
- ⭐ Customer Rating Analysis
- 🎯 Interactive Filters & Slicers
